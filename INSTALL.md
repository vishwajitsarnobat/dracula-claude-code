### [Claude Code](https://claude.com/claude-code)

#### Install with the script

```sh
curl -fsSL https://raw.githubusercontent.com/vishwajitsarnobat/dracula-claude-code/main/install.sh | bash -s -- --activate dracula
```

Use `--activate alucard` for the light theme.

#### Install using Git

If you are a Git user, you can install the theme and keep it up to date by cloning the repo:

```sh
git clone https://github.com/vishwajitsarnobat/dracula-claude-code.git
cd dracula-claude-code
./install.sh
```

#### Install manually

Download using the [GitHub `.zip` download](https://github.com/vishwajitsarnobat/dracula-claude-code/archive/main.zip) option and unzip it. Copy `themes/dracula.json` (and `themes/alucard.json` if you want the light theme) into `~/.claude/themes/`.

#### Activating theme

1. Open Claude Code.
2. Run `/theme`.
3. Pick Dracula or Alucard.
